# Bambu Radar – מכ"ם שמועות וחדשות על Bambu Lab

אתר שאוסף בזמן אמת חדשות, שמועות ודליפות על Bambu Lab, מסווג אותן (שמועה / רשמי / חדשות / קהילה), ומאפשר לשאול צ'אט AI שעונה בעברית על סמך מה שנאסף, עם קישורים למקורות.

## הרצה מקומית (2 דקות)

דרוש Node.js 20 ומעלה. **אין צורך ב-`npm install`** – הפרויקט בלי תלויות חיצוניות.

```bash
cp .env.example .env      # ואז ממלאים ANTHROPIC_API_KEY
node server.js
```

פותחים http://localhost:3000

בלי מפתח API האתר והאיסוף עובדים, והצ'אט מחזיר רשימת כתבות קרובות בלבד.

## איך זה עובד

| רכיב | קובץ | תפקיד |
|---|---|---|
| אוסף | `lib/collector.js` | לולאה שרצה כל שנייה ובודקת איזה מקור הגיע זמנו להיבדק |
| מקורות | `lib/sources.js` | Reddit, Google News, Bing News, Hacker News, הבלוג הרשמי, יוטיוב (אופציונלי) |
| סיווג | `lib/classify.js` | זיהוי שמועות לפי מילות מפתח (leak, patent, FCC, reportedly…) + תיוג מוצרים |
| אחסון | `lib/store.js` | קובץ JSON, הסרת כפילויות לפי קישור וכותרת |
| תרגום | `lib/translate.js` | כל כתבה חדשה מתורגמת לעברית ברקע (Claude Haiku) ומופיעה מתורגמת בפיד בלי רענון |
| צ'אט | `lib/chat.js` | Claude מתרגם את השאלה לחיפוש, השרת שולף כתבות, Claude עונה עם מקורות |
| זמן אמת | `/api/stream` | Server-Sent Events: פריט חדש מופיע בדפדפן מיד, בלי רענון |

## תרגום לעברית

כותרות ותקצירים באנגלית מתורגמים אוטומטית, ובפיד מופיע תג "מתורגם". תיבת הסימון מעל הפיד מחזירה לטקסט המקורי, והבחירה נשמרת בדפדפן. התרגום שומר על שמות מוצרים באנגלית ועל רמת הוודאות: שמועה נשארת שמועה. החיפוש עובד גם בעברית.

התרגום דורש `ANTHROPIC_API_KEY`, והעלות קטנה כי משתמשים במודל הקל. לכיבוי: `TRANSLATE=off`.

## על "מתעדכן כל שנייה"

- **הדפדפן** מקבל פריטים חדשים מיד כשהשרת מוצא אותם, והחיווי "בדיקה אחרונה לפני X שנ׳" מתעדכן כל שנייה.
- **המקורות** נבדקים אחת ל-90 עד 300 שניות. Reddit, Google ועוד חוסמים בדיקות בתדירות גבוהה. אפשר להוריד עד 5 שניות עם `POLL_SECONDS=5`, אבל צפוי שיחסמו אותך, ולכן לא מומלץ.
- שמועה שמתפרסמת ב-X/טוויטר או בטלגרם לא תיאסף, כי אין להן פיד חינמי יציב.

## כיסוי מקורות: מה נאסף ומה לא

נאסף ללא מפתח: Reddit (הקהילה, שמועות וחיפוש כללי), הפורום הרשמי של Bambu Lab, Mastodon (תגיות #bambulab ו-#bambustudio), Hacker News, גרסאות Bambu Studio ב-GitHub, הבלוג הרשמי, Google News ו-Bing News, וגם חדשות בגרמנית, יפנית, סינית, צרפתית, ספרדית ועברית. כתבות בשפות אחרות מתורגמות לעברית.

חיפוש רחב יותר בכל האינטרנט: מגדירים `BRAVE_API_KEY` והשרת יריץ חיפושים של שמועות ודליפות בכל הרשת.

לא נאסף, ואי אפשר לעשות זאת בחינם ובצורה מותרת: X/טוויטר, פייסבוק, אינסטגרם, טיקטוק, טלגרם ודיסקורד. הם חוסמים איסוף אוטומטי או דורשים API בתשלום או אישור. אפשר לעקוף חלקית עם ערוצי יוטיוב (`YOUTUBE_CHANNEL_IDS`) או עם שירות חיפוש רשת בתשלום. לא קיים כלי שסורק את כל הפורומים בעולם, ולכן המערכת מכסה את המקורות הפתוחים המרכזיים ולא "הכל".

## הוספת מקורות

- ערוצי יוטיוב: `YOUTUBE_CHANNEL_IDS=UCxxxx,UCyyyy` (מזהה הערוץ מופיע בקישור לערוץ)
- פיד RSS נוסף: `EXTRA_FEEDS=שם|https://site.com/feed|news`
- או עריכה ישירה של `lib/sources.js`

## העלאה לאינטרנט

האתר צריך שרת שרץ כל הזמן (לא אחסון סטטי), ודיסק קבוע ל-`DATA_DIR` אם רוצים לשמור היסטוריה.

- **Railway / Render / Fly.io:** מחברים את התיקייה (או מעלים ל-GitHub), הם מזהים את ה-`Dockerfile`. מגדירים משתני סביבה `ANTHROPIC_API_KEY` ו-`DATA_DIR=/data`, ומחברים Volume ל-`/data`.
- **Docker:**
  ```bash
  docker build -t bambu-radar .
  docker run -p 3000:3000 -v radar-data:/data -e ANTHROPIC_API_KEY=sk-... bambu-radar
  ```

שים לב: Reddit לפעמים חוסם כתובות של שרתי ענן. אם מקור מסוים מסומן בתקלה (מופיע מעל הפיד), האתר ממשיך לעבוד עם שאר המקורות.

## עלויות ואבטחה

- הצ'אט משתמש ב-API בתשלום. יש הגבלה של 15 הודעות לדקה לכל כתובת (`CHAT_PER_MINUTE`).
- המפתח נשמר רק בשרת ולא נחשף לדפדפן. לא מעלים את `.env` ל-GitHub (כבר ב-`.gitignore`).
- תוכן הכתבות מועבר ל-Claude כנתונים בלבד, עם הנחיה להתעלם מהוראות שמופיעות בתוכו.
